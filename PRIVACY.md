# Privacy Policy — Drive MCP Local

Last updated: 2026-10-28

Drive MCP Local is a personal tool used only by its owner (jinukahn98@gmail.com) to access the owner's own Google account data from the owner's own computer.

- **Data accessed:** Google Drive, Docs, Sheets, Slides and Calendar data of the signed-in owner, only when the owner asks the tool to.
- **Storage:** OAuth tokens are stored locally on the owner's computer. No data is sent to or stored on any server operated by the developer.
- **Sharing:** Data is not sold, shared, or transferred to third parties.
- **Google API Services User Data Policy:** Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
