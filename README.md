# Drive MCP Local

Personal, single-user tool that lets the owner's local AI assistant access the owner's own Google Drive, Docs, Sheets, Slides and Calendar.

Homepage: https://github.com/jinukahn98-lab  
Privacy policy: [PRIVACY.md](PRIVACY.md)

## Agensi skill packaging

Agent workflow skill for marketplace submission (separate from the MCP server) lives under [`agensi/`](agensi/). Build the upload ZIP with:

```bash
./agensi/scripts/build-submission-zip.sh
```
